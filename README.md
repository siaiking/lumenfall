Lumenfall is a neon arena survival shooter: you are the last Warden, holding a single lantern of light against waves of the Hollow. Survive the swarm, draft an upgrade after every wave, and face the Gloomlord every fifth wave. WASD to move, mouse to aim, hold click to shoot, Shift to dash. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files under `game/`.
